Dig Forever is a infinite digging simulator similar to Mr Driller. The Objective of the game is to get as high of a score as possible (unfinished concept). There are two kinds of tiles to dig: colored tiles, and tough tiles. The colored tiles take just one hit to destroy, and the tough tiles take five. To gain score, destroy tiles. The gain even more score, destroy tiles that are in groups. To gain even morer scorer, have tiles fall onto a group of four or more tiles, destroying the whole group. 

Controls:
  - A / D: Move left / right + aim the dig in respective direction
  - W / S: Aim the dig up / down
  - Space: Jump
  - J:     Dig in the direction you are aiming
  - Esc:   Quit

Prerequisites:
  - Git
  - CMake 3.25 or newer
  - A c++17 compiler
  - An internet connection for first build (to download raylib)

How to run on windows:
  1. Clone the Repo, git clone https://github.com/TJK-S/DigForever.git
  2. Open project directory
  3. Run command cmake -S . -B build
  4. Run command cmake --build build
  5. Open game main.exe
